# Data dictionary: tract model table

`data/processed/tracts_all.parquet` (built by `scripts/02_build_tract_table.py`; released as `deliverables/dataset/tracts_model_table.csv`): 9,794 rows (one per study tract), 112 columns. Generated by `scripts/13_data_dictionary.py` from the table itself, so the missing counts and ranges are exact.

**Roles.** *model input*: in `coverage_risk.model.STRUCTURAL`, the only columns the expectation model may use. *structural*: built from the same sources but not a model input. *outcome*: the counts the model predicts. *provenance*: where the map's features come from (used in H4 and descriptives, never as model inputs). *reference*: independent counts used only to validate. Audit strata (SVI, CVI, rurality, tribal, hazards) are deliberately **not** in this table; they are in `data/processed/strata_audit.parquet`.

Counts by role: model input 66, provenance 25, reference (validation only) 8, descriptive 4, identifier 3, geometry 2, outcome (buildings) 2, structural 1, outcome (places) 1.

Conventions: ratios use a zero-safe denominator, so a tract with no housing units has missing (not infinite) shares; `log` means natural log of (1 + x). The 2023 and 2026-10 counts (`r2023_*`, `r2026b_*`) are added later in `scripts/07_catchup.py`.
